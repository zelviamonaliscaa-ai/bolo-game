# 小Bolo · 十胜之光

手机竖屏网页游戏：九夜蓄力、弓箭挑战、巨像焚烧、光流成长与星河冥想。

全部游戏文件、图片、中文字体和音乐均已包含，无需安装依赖。

## GitHub Pages 发布

在本仓库 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)，保存。

## 本地运行

在本目录运行 `python3 -m http.server 8000`，再访问 http://localhost:8000。请通过网页服务器打开，不要直接双击 HTML。
